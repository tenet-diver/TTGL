but bundled SBOM scanning finds further affected components. A second candidate
also updates to the latest inspected `hf-xet 1.8.0` and `virtualenv 21.15.9`.

The embedded wheel versions were checked in the actual archives. A versionless
filelock SBOM query is explicitly unresolved, not a confirmed finding.

identifies the exact versions, advisories and scope. Both complete candidates

vulnerabilities block affected candidates. The Codespace exception for incomplete
evidence does not waive confirmed findings. No API-key/remote-embedding workaround,
model fallback or fabricated baseline score was used.
