# Online task memory: integration checkpoint

8 November 2026. **Full long-horizon testing is not complete.** This report
records the additional online integration work after the completed
[memory-QA study](smallville-results.md), whose negative promotion decision
remains unchanged. No global memory default has been adopted.

The incremental system can collect useful task information: implementation
decisions, attempts, exact command/check source IDs and remaining uncertainty.
In the successful restarted-session diagnostic, the agent searched the earlier
notes, opened the cited original results, rechecked behavior, saved a code
extension and passed an independent post-generation check. This was deliberately
prompted memory use on a synthetic utility. It establishes integration, not
autonomous memory use, long-range efficacy or an economic advantage.

## Changes tested

The storage layer appends immutable visible source records with hashes, paginates
raw output and supports revisions while retaining superseded notes. An agent note
always remains a fallible assertion, including when it cites a passing command.
SQLite FTS provides lexical retrieval to every condition. The memory candidate
additionally uses the already reviewed local BGE model for instructions/notes;
transient command logs do not each incur an embedding, importance-rating or
reflection model call. No new dependency or model service was installed.

The native bridge exposes only the owned task container as UID1000 and its own
records. It cannot select another UID, container or arbitrary host path. Exact
command output survives truncation, command nonzero exits remain observations,
RPC identities prevent duplicate execution, and uncertain operations are never
automatically replayed. Invocation-local permissions cover only its four tools;
normal host routing, sandbox permissions and hook trust are unchanged.

Twenty-four storage/bridge software checks pass. Five scheduler checks cover full
horizon retention, fresh/continued native identities, refusing replay of a started
matrix and stopping uncertain model calls before grading. A pre-generation
allocation/hash guard also prevents the earlier protocol-attachment mistake.
Two additional native scope checks reject another server using an allowed tool
name and preserve failed calls as evidence. This stricter result validator was
also replayed successfully against all eight actual prior CLI outputs with zero
new model calls; it uses the same tested generation command.

The existing reviewed immutable runtime replaces blocked upstream images. Task
code, hidden data and private solutions never enter model memory. Grading runs
after actor state is sealed and the actor stops.

Final fuzz controls 003 preserve the original module name and access to the
already reviewed Python dependency directory. Earlier controls 002 (empty score
0.2119/reference 0.9154) remain retained; the empty fuzzer uses randomness and its
score is not expected to be identical between independent controls.

Two actual verifier-launched adversarial fuzz workers also confirm UID1000, zero
effective capabilities, denied writes to private grader/coverage/reward paths and
no access to parent parser/wrapper objects. The trusted fuzz supervisor alone can
terminate its child; the untrusted worker retains no such capability.

The final configuration/SQLite adapters also give only the trusted root
supervisor the capability needed to terminate a child after it drops UID. Actual
timeout controls reap both children and confirm that task actors still have zero
effective capabilities. Configuration empty/private control 011 passes; SQLite
003 repeats its expected empty failure/reference 1.0. The completed full reference
010 is retained and reused with a strict source-equivalence audit: only versioned
imports and the supervisor cleanup capability differ, not the daemon, candidate
runner or verifier bodies. No successful witness is silently rerun or replaced.

All preparation failures are retained: directory traversal/permissions, read-only
nested mount preparation, root-only coverage output placement and reference bind
mount replacement. They made zero agent-model calls. Original task comparison
and threshold logic is retained, but fuzz IPC changes throughput and the runtime
differs from upstream. Future results are **adapted LHTB-derived scores**, not
official leaderboard results. Artifact-policy review remains separate from scores.

## Remaining registered work

[The plan](smallville-online-plan.md) and
[development protocol](../../tools/usage-monitor/studies/online-longhorizon-protocol-001.json)
specify nine assignments: three reserved development tasks crossed with continued
native context/lexical records, fresh checkpoints/lexical records, and fresh
checkpoints/incremental semantic memory. Original 4h/1.5h/3h horizons are preserved:
25.5 actor-hours, 15-minute checkpoints and at most 102 native processes. This
matrix started at 14:43 UTC on 8 November after all 13 readiness gates passed.
The first continued-context assignment is running; no final task grade is yet
available. Its first phase reconciles 35 unique responses, 767,014 native tokens
and 4.5317 frozen-rate scenario credits. These are interim counters, not an
additional cost to add again when the full assignment is measured. No reserved
validation task contents have been inspected.

Continued sessions receive full task instructions once and short continuation
messages thereafter; they do not pay for redundant instruction replay. All arms
have the same public task information, visible artifacts and own records/notes.
The continued control uses the same fixed checkpoints and pauses as the other
conditions; comparisons apply to that harness and its observed cache behavior.
Private grades never feed live decisions. A candidate must preserve every matched
control success, lower total model-rate scenario cost by at least 10% against each
control, and win at least two of three paired costs against each before nomination.
Only a frozen qualifying candidate may advance to separate fresh validation.
Passing this tiny development block would still not establish noninferiority.

Langfuse and TTGL remain running. Research schedules remain paused; this is active
chat work. Raw captures, source/permission receipts, private grading data and
delivery ledgers remain private. The original corpus was relocated byte-for-byte
to the larger temporary volume with a verified hash and retained original-path
link; no completed study was deleted or rerun.

During this matrix, the existing Langfuse exporter focuses its HTTP capture input
on the dedicated study proxy while continuing to import all native sessions.
Normal HTTP captures remain queued and will be flushed through the same ledger
when the normal capture input is restored. Model counters are never summed with
the proxy-span dataset.
