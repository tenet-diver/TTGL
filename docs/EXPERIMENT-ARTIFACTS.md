# Public experiment artifact inventory

Snapshot: 15 November 2026. Read the [interpreted results](EXPERIMENTS.md) first.

This inventory lists public study records and top-level research collections. A
protocol/reservation is a design, not a completed trial. Files named results can
record failure, an unexercised gate or an incomplete cost. Multiple versions
and audits can describe the same model calls: do not add them together. Raw
private attempts and credentials are intentionally excluded.
